about

I came into software from a mechanical engineering background — a B.E. from M. Kumarasamy College of Engineering, plus a filed patent for a solenoid-actuated EV charging mechanism. That training shaped how I approach backend work: define the constraints, design the structure, then build something that holds up under real conditions.

Today that means writing clean Python, building REST APIs in Flask, and designing relational schemas in MySQL and SQLite that keep data consistent as an application grows. I like the parts of backend work that are closest to engineering discipline: authentication, session management, input validation, and code that's easy for someone else to pick up later.
